# UAV Center

Python/Django ve Vue 3 ile geliştirilen, yerel çalışma odaklı bir mühendislik
operasyonları platformu.

## Teknolojiler

- Backend: Python, Django ve Django REST Framework
- Frontend: Vue 3, Vite ve Naive UI

## Genel Yetenekler

- Kullanıcı ve rol yönetimi
- Yerel yapay zekâ modelleriyle sohbet
- Ses transkripsiyonu
- Asenkron görev işleme ve ilerleme takibi
- Filtreleme ve gösterge panelleri
- Kurulabilir web uygulaması (PWA) desteği

## Kapsam

Bu depo, projenin genel tanıtımını içerir. Uygulama kaynak kodu bu depoda
yayımlanmamaktadır.
